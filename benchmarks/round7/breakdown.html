Table view

Each type is scored on its own, across every dev set that labels it; the public benchmarks' own labels are mapped to the same types (for example Gretel's ssn to SSN, bank_routing_number to account number). “Address” includes street, city and postcode lines. “Other” is Gretel en-v1's non-name details, which that benchmark does not type. The generated lists set is left out: its text differs on every run, so it can't be compared across models.
